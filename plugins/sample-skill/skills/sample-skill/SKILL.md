# Sample Skill

This is a sample skill plugin for the Indigital Studio marketplace. It demonstrates the structure that all plugins in this marketplace follow.

## What it does

When activated, the agent greets the user with a friendly, personalized message.

## How to use

Ask the agent to greet you, or simply say "hello" during a session where this skill is installed.
